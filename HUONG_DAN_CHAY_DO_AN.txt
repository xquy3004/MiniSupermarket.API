CÁCH 1: CHẠY TRỰC TIẾP NHANH BẰNG FILE .EXE (KHÔNG CẦN CẤU HÌNH VS)
------------------------------------------------------------------------
Bước 1: Chạy Backend Web API (Cổng 5000):
   - Mở thư mục: MiniSupermarket.API\bin\Debug\net8.0\
   - Nhấp đúp chạy: MiniSupermarket.API.exe
   - (Cửa sổ Kestrel màu đen sẽ hiện lên lắng nghe cổng http://localhost:5000)

Bước 2: Chạy Frontend WinForms:
   - Mở thư mục: MiniSupermarketWinForms\bin\Debug\
   - Nhấp đúp chạy: MiniSupermarketWinForms.exe
   - Giao diện đăng nhập Baby Care Store hiện đại sẽ xuất hiện ngay lập tức!

------------------------------------------------------------------------
CÁCH 2: CHẠY BẰNG VISUAL STUDIO 2022
------------------------------------------------------------------------
Bước 1: Nhấp đúp mở file solution: MiniSupermarket.API.sln

Bước 2: Cấu hình chạy đồng thời cả Backend và WinForms (Multiple Startup Projects):
   1. Nhấp chuột phải vào dòng đầu tiên: "Solution 'MiniSupermarket.API' (3 of 3 projects)" trong Solution Explorer.
   2. Chọn "Properties" (hoặc "Configure Startup Projects...").
   3. Chọn mục "Multiple startup projects":
      - MiniSupermarket.API        --> Action: Start
      - MiniSupermarketWinForms    --> Action: Start
   4. Bấm Apply --> OK.
   5. Bấm nút "Start" (F5) màu xanh trên thanh công cụ.

(Hoặc nếu chỉ muốn chạy giao diện WinForms khi API đã bật:
 Nhấp chuột phải vào MiniSupermarketWinForms --> Chọn "Set as Startup Project" --> Bấm Start F5).
